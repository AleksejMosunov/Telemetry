# Анализ телеметрии картинга

Веб-приложение для разбора логов AiM (MyChron / Solo). Читает CSV-экспорт из
RaceStudio 3, само определяет трассу и повороты по GPS, сравнивает от одного
до шести пилотов.

Всё считается **в браузере** — файлы никуда не загружаются.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/ — можно открыть с телефона
npm test         # прогон анализа на файлах из csv/ с проверками целостности
```

## Что нужно от экспорта

RaceStudio 3 → экспорт в CSV. Критично:

- **обязательно включить `GPS Latitude` и `GPS Longitude`** — без координат
  не строится трасса и разваливается весь анализ;
- не прореживать частоту (оставить исходные 10–25 Гц);
- выгружать всю сессию, а не только лучший круг.

Каналы `YawRate`, `GPS LatAcc`, `GPS LonAcc` не обязательны — без них просто
не будет метрик стиля руления и использования сцепления.

## Как это устроено

Ключевая идея: круги нельзя сравнивать по времени или по пройденной
дистанции — пилоты едут разными траекториями. Поэтому:

1. по лучшему кругу строится **осевая линия трассы**, ресэмплится с шагом 1 м;
2. каждая точка каждого круга **проецируется** на эту линию → «метр по кругу»
   плюс боковое смещение;
3. повороты нарезаются **по кривизне осевой линии** — это свойство трассы,
   а не пилота, поэтому нарезка не зависит от того, кто едет;
4. зоны (торможение + поворот + выход) покрывают круг целиком, поэтому
   потери по зонам суммируются точно в дельту круга — это и есть главная
   проверка корректности, её гоняет `npm test`.

### Структура

```
src/core/      чистая аналитика, без React — переносится куда угодно
  parse.ts     разбор AiM CSV
  geo.ts       проекция координат, фильтр Савицкого-Голея
  track.ts     нарезка кругов, осевая линия, поиск поворотов
  align.ts     проекция на осевую, ресэмпл по дистанции
  analysis.ts  разбор круга, статистика по зонам
  pipeline.ts  оркестрация: файлы → готовый анализ
src/ui/        интерфейс
src/worker.ts  анализ в фоновом потоке, чтобы не подвешивать вкладку
scripts/       исследовательские прогоны, которыми проверялись выводы
```

Загрузчик отделён от аналитики: чтобы читать `.xrk` напрямую, достаточно
заменить `parse.ts` — остальное не меняется.

## Оговорки

- Точка начала замедления определяется по GPS с точностью около 2–5 м.
  Для сравнения пилотов между собой этого достаточно: ошибка одинаковая у всех.
- Тормоза и газа в данных нет, фазы восстанавливаются по динамике скорости.
- Заезды в разное время суток различаются ещё и температурой трассы —
  приложение отмечает это отдельной оговоркой во вкладке «Выводы».
